# Privacy

Swamp Fish Control Room is designed to run locally in the browser/PWA.

- No account is required.
- No analytics are included.
- No test readings or photos are uploaded by the app.
- Saved readings and photos remain in browser storage on the device.
- A user can export a JSON backup manually. Exported backups omit photos.
- Removing the app/browser site data can remove locally stored history, so backups are recommended for long-term records.
